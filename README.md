<div align="center">
  <h2>🚀 Evolução e Aprendizado</h2>
  <p align="justify">
    Este projeto representa um marco na minha jornada como desenvolvedor. Inicialmente, ele foi um desafio que eu não possuía maturidade técnica para concluir com total liberdade. Antes, os valores eram atribuídos a variáveis fixas e a conversão funcionava apenas do Real para outras moedas.
  </p>
  <p align="justify">
    <b>A virada de chave:</b> Através do estudo de <b>Consumo de APIs</b>, refatorei o sistema para buscar informações em tempo real de um servidor sobre as cotações do Dólar, Euro, Bitcoin e Libra. Além disso, reestruturei o HTML e a lógica para permitir a operação de <b>qualquer moeda para qualquer outra moeda</b> disponível no projeto.
  </p>
</div>
